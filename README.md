# nss-tgpcop-

Official National Service Scheme (NSS) Portal for Tulsiramji Gaikwad-Patil College of Pharmacy (TGPCOP).

## Features
- **Online Volunteer Registration**: Student enrollment with photo upload and validation
- **Application Tracking**: Real-time status lookup and review notifications
- **Digital Volunteer ID**: Verifiable digital ID card with QR code and high-res PNG download
- **Instant QR Verification**: In-browser camera scanning and token verification via Supabase RPC
- **Coordinator Desk**: Comprehensive administrative management for volunteer approvals, rejections, card revocations, leadership directory, and CSV export

## Architecture
- Vanilla HTML5 / CSS3 / JavaScript
- Supabase (PostgreSQL, Storage, RLS, Auth, RPC)
- Vercel Deployment

## Development & Build

node build.js
